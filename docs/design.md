# 설계 노트

발표 자료(`project_proposal.pptx`)의 내용을 코드와 연결해 정리한 문서입니다. 숫자는 설계 시점의 파일럿(최신 30편)에서 나온 것이고 결과가 아닙니다.

## 1. 연구 설계

| 항목 | 결정 | 이유 |
|---|---|---|
| 역지표의 정의 | 발언 톤과 이후 초과수익률의 **음의 관계** | 적중률(상승/하락 맞히기)은 시장 상승기에 흔들림. 초과수익률과 알파가 기준선 문제를 줄임 |
| 분석 단위 | 월. 월 t 발언 → 월 t+1 수익률 | 수업 Case 1 데이터가 월별. 미래 정보 사용 방지 |
| 표본 기간 | 2018-10 ~ 2025-12 (87개월) | 채널 개설 2018-09 이후, 수업 수익률 데이터 끝(2025-12)까지 |
| 대상 | 한국 상장 종목(H1), 코스피(H2) | 수업 데이터에 미국 종목·암호화폐가 없음 |
| 영상 | 단독 영상만, 게스트 대담 영상은 제외 | 파일럿에서 게스트 영상은 감성이 더 높고(+0.75%p) 시장 언급이 거의 없음. 스크립트에 화자 구분이 없음 |
| 문장 | 전망 문장만 톤 계산에 사용 | 밈은 '예측'에 관한 것. 사전 점수는 '일어난 일'의 단어도 세기 때문 |

## 2. 텍스트 수치화

- **사전(dictionary)**: 한국어 긍정/부정/불확실/약한 확신/강한 확신 단어 목록(`text/lexicon_ko.py`). 점수 = 단어 수 ÷ 전체 단어 수, 감성 = 긍정 − 부정(Case 4 정의). 종목-월 단위로는 단어 수를 합친 뒤 비율을 구함.
- **LLM**: 문장별 sentiment(−2~+2), uncertainty(0~2), forward(전망 여부)를 JSON 으로 받음. 결과를 모른다고 가정하게 하는 규칙과 예시 포함. 캐시와 형식 오류 재시도.
- **교차 검증**: 문장을 영어로 번역해 VADER·FinBERT 적용(`pip install .[nlp]`).
- **타당성**: 문장 약 100개를 2명 이상이 라벨링 → 라벨러 간 일치도(kappa) → 모델-사람 상관, 부호 일치율.

## 3. 수익률 분석 (수업 Case 1 엔진, 정렬 변수만 베타 → 톤)

1. 월 t 의 종목 톤으로 P(톤 > 0) / N(톤 < 0) 그룹을 만든다.
2. 월 t+1 의 균등가중 초과수익률(r = R − Rf)을 그룹별로 계산한다. 그룹마다 `min_per_group` 종목 미만인 달은 제외.
3. H−L = P − N 을 시장 초과수익률에 회귀: `(r_P − r_N)(t+1) = α + β·r_m(t+1) + ε`. Newey-West 표준오차(기본 3 시차).
4. H1: α < 0. H2: `r_m(t+1) = a + b·Tone_z(t) + e` 에서 b < 0.
5. 점검: 같은 그룹의 t−1, t, t+1 H−L 평균(사전 추세와 동시 반응), 검정력 어림 계산.

## 4. 판정 규칙 (`analysis/decision.py`)

결과를 보기 전에 정했습니다. `meaningful_alpha`(기본 월 2%)는 설정에서 바꿀 수 있습니다.

| 판정 | 조건 |
|---|---|
| 지지 | 알파가 음수이고 5%에서 유의하며, 사전 추세가 유의하지 않음 |
| 지지 보류(사전 추세) | 알파는 유의한 음수지만 발언 전 달에도 H−L 이 유의함 |
| 반대 방향 | 알파가 유의한 양수 |
| 기각(월 단위) | 신뢰구간 하한이 −meaningful 보다 크고(의미 있는 음의 효과 배제) 위 조건에 해당하지 않음 |
| 판정 불가 | 위에 해당하지 않거나 분석 가능한 달이 `min_months` 미만 |

'기각'은 **월 단위에서만** 말할 수 있습니다.

## 5. 파일럿에서 얻은 설계 조정 (30편, 2026-10~11)

- 자막 수집 30/30 성공. 자동 생성 한국어 자막이라 줄바꿈·`[음악]` 태그 정리 필요.
- 게스트 대담이 16/30편(53%)이고 상영 시간으로는 73% → 제외.
- 단독 영상(14편)의 언급 종목은 삼성전자·SK하이닉스·삼성전기 3개 → 시장 수준 분석 병행.
- 사전 점수는 설명 문장의 단어(성장, 반등)에 끌려 전망 톤을 놓칠 수 있음 → 전망 문장 필터와 LLM 채점.
- 한국어 DTM 은 조사 때문에 같은 종목이 흩어짐("삼성전자", "삼성전자가", …) → 사전 점수는 DTM 일치가 아니라 문자열 포함으로 셈.

## 6. 선행 사례

- 공개 GitHub 프로젝트(전반꿀 연구소): 영상 **제목**을 LLM 으로 분류하고 다음 거래일 종가의 상승/하락 방향으로 적중률을 계산. 벤치마크 조정과 유의성 검정이 없음.
- Inverse Cramer Tracker ETF(SJIM, Tuttle Capital): 운용자의 재량 판단으로 크레이머 추천의 반대로 투자. 출시 후 약 −15%(같은 기간 S&P 500 약 +25%), 약 11개월 만에 청산 발표. 이 결과만으로 밈을 입증하거나 반증할 수 없음(시장 상승기, 재량 판단).
- Engelberg, Sasseville & Williams (2012), *Management Science*: 크레이머 추천 직후의 야간 이상수익률과 이후 반전, 종목 선택 능력의 증거는 약함. 수치는 원문에서 확인할 것.
